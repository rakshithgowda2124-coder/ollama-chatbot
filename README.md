## Features

* Clean chatbot UI
* Direct integration with Ollama API
* Real-time AI responses
* Local LLM execution

## Tech Stack

* HTML
* CSS
* JavaScript
* Ollama
* Llama 3.2

## How to Run

1. Install Ollama
2. Pull the model:

```bash
ollama pull llama3.2
```

3. Run Ollama:

```bash
ollama run llama3.2
```

4. Open index.html in your browser
